Superstore Data Analytics Project

Project Overview

This project focuses on analyzing Superstore sales data to identify business insights, sales trends, customer segments, product performance, and profitability.

The project uses Python, MySQL, and Power BI to perform data cleaning, data analysis, and interactive dashboard creation.

Tools & Technologies

- Python: Data cleaning and preprocessing
- MySQL: Data storage and SQL analysis
- Power BI: Interactive dashboard and data visualization
- Jupyter Notebook: Python development

Project Workflow

1. Imported the Superstore dataset.
2. Cleaned and preprocessed the data using Python.
3. Stored the cleaned dataset in MySQL.
4. Performed SQL queries to analyze sales and profit.
5. Connected MySQL to Power BI.
6. Created an interactive dashboard.

Power BI Dashboard

The dashboard includes the following KPIs:

- Total Sales
- Total Profit
- Total Orders
- Average Discount

Visualizations

- Sales Trend
- Sales by Category
- Sales by Segment
- Sales by State
- Sales by Shipping Mode

Interactive Filters
